# ⚡ Fashion Assistant - Быстрый старт

## 🎯 Что это?

**Fashion Assistant** — MVP мобильного приложения для управления виртуальным гардеробом и создания образов с AI-оценкой. Аналог Acloset, но проще и дешевле.

## 📦 Что внутри?

### ✅ Реализованные функции
- 👔 **Виртуальный гардероб** с фото
- 👗 **Конструктор образов**
- 🤖 **AI-оценка** (0-100 баллов)
- 💡 **Рекомендации** по улучшению
- 📸 **Камера + галерея**
- 🎨 **Material Design 3**

### ❌ Убранные функции (для удешевления)
- AR-примерка
- Социальная сеть
- Облако
- Интеграции с магазинами

## 🚀 Запуск за 5 минут

### Шаг 1: Откройте проект
```bash
Android Studio → File → Open → выберите /workspace
```

### Шаг 2: Дождитесь Gradle Sync
- Автоматически скачает библиотеки
- ~2-3 минуты

### Шаг 3: Запустите
```
Нажмите ▶️ (Run) или Shift+F10
```

### Шаг 4: Тестируйте!
1. Добавьте 3-4 вещи в гардероб (кнопка +)
2. Создайте образ (вкладка "Образы" → +)
3. Выберите вещи
4. Нажмите "Оценить образ"
5. Получите оценку и рекомендации!

## 🧠 Как работает AI?

```
Формула оценки:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Базовая оценка:              50 баллов
                              ↓
+ Полнота образа:          0-30 баллов
  (верх + низ + обувь)
                              ↓
+ Гармония цветов:         0-20 баллов
  (тёплые/холодные/нейтральные)
                              ↓
- Штрафы:                  0-20 баллов
  (дубликаты категорий)
                              ↓
+ Бонусы:                   0-5 баллов
  (аксессуары)
                              ↓
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
= ИТОГОВАЯ ОЦЕНКА:         0-100 баллов
```

### Примеры

**90+ баллов 🌟**
- Полный образ (верх+низ+обувь)
- Гармоничные цвета (нейтральные + акцент)
- Есть аксессуары

**70-89 баллов ✨**
- Полный образ
- Хорошее сочетание цветов
- Может быть без аксессуаров

**50-69 баллов 👍**
- Базовый образ
- Средняя гармония цветов
- Могут быть небольшие недочёты

**< 50 баллов 📝**
- Неполный образ
- Конфликт цветов
- Нужны улучшения

## 🐛 Частые проблемы

### Gradle sync failed
```bash
./gradlew clean
./gradlew --stop
File → Invalidate Caches / Restart
```

### Эмулятор не запускается
```
Tools → Device Manager → Wipe Data
Или создайте новый эмулятор
```

### Приложение крашится
```
Проверьте права доступа к камере/галерее
Очистите данные приложения
Пересоберите: Build → Rebuild Project
```

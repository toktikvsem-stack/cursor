# Fashion Assistant MVP - Итоговый отчёт

## 📋 Обзор проекта

Разработано полнофункциональное MVP Android-приложение **Fashion Assistant** — аналог Acloset, но с упрощённым функционалом для тестирования идеи и снижения стоимости разработки.

### ✅ Что реализовано

#### Основные функции
1. **Виртуальный гардероб**
   - Добавление фотографий одежды через камеру или галерею
   - Каталогизация по категориям: верх, низ, платья, обувь, верхняя одежда, аксессуары
   - Указание цвета и других атрибутов
   - Удаление вещей из гардероба
   - Отображение в виде красивой сетки с фото

2. **Конструктор образов**
   - Выбор нескольких вещей из гардероба
   - Визуальное отображение выбранных элементов
   - Сохранение образов с названием
   - Просмотр всех созданных образов

3. **AI-оценка образов**
   - Автоматическая оценка по 100-балльной шкале
   - Анализ полноты образа (верх + низ + обувь)
   - Проверка цветовой гармонии (нейтральные, тёплые, холодные тона)
   - Выявление несоответствий (дубликаты категорий)
   - Бонусы за аксессуары
   - Детальная обратная связь с рекомендациями

4. **Современный UI**
   - Material Design 3
   - Поддержка светлой и тёмной темы
   - Адаптивный дизайн
   - Плавные анимации и переходы
   - Интуитивная навигация

### ❌ Что убрано (сложные/дорогие функции)

- AR-примерка одежды
- Социальная сеть и лента пользователей
- Интеграции с магазинами
- Погодные рекомендации с API
- Календарь образов
- Облачная синхронизация
- Машинное обучение (используются правила вместо ML)

## 🎨 AI-движок оценки образов

### Алгоритм работы

```kotlin
Оценка образа (0-100 баллов):

1. Базовая оценка: 50 баллов

2. Полнота образа (+30 макс):
   ✓ Верх + Низ + Обувь = +30
   ✓ Верх + Низ = +20
   ✓ Платье + Обувь = +30
   ✗ Неполный образ = +10

3. Цветовая гармония (+20 макс):
   • Нейтральные цвета: черный, белый, серый, бежевый
   • Тёплые: красный, оранжевый, желтый, розовый
   • Холодные: синий, голубой, фиолетовый, зеленый
   
   Оценка:
   ✓ Много нейтральных = +10
   ✓ Нейтральные + акцент = +8
   ✓ Только тёплые/холодные = +7
   ⚠ Микс тёплых и холодных = +3
   ✗ Больше 3 цветов = -5

4. Дубликаты категорий:
   ✗ 2 верха/низа = -10 за каждый

5. Бонусы:
   ✓ Аксессуары = +5

6. Итоговая оценка: clamp(0, 100)
```

### Примеры оценки

**Пример 1: Идеальный образ (95 баллов)**
- Белая рубашка (верх)
- Черные брюки (низ)
- Коричневые туфли (обувь)
- Часы (аксессуар)

Расчёт: 50 + 30 (полный) + 10 (нейтральные) + 5 (аксессуар) = 95

**Пример 2: Хороший образ (68 баллов)**
- Синяя футболка (верх)
- Джинсы синие (низ)
- Кроссовки (обувь)

Расчёт: 50 + 30 (полный) - 12 (монохром) = 68

**Пример 3: Неполный образ (40 баллов)**
- Красное платье
- Зелёные кроссовки
- Синий шарф

Расчёт: 50 + 10 (неполный) - 10 (конфликт тёплых/холодных) - 10 (платье+низ) = 40

## 📱 Руководство пользователя

### Первое использование

1. **Запустите приложение**
   - Откроется экран "Гардероб" (пустой)

2. **Добавьте первую вещь**
   - Нажмите кнопку "+" (FAB внизу справа)
   - Выберите "Сфотографировать" или "Выбрать из галереи"
   - Разрешите доступ к камере/галерее
   - Сделайте фото или выберите из галереи
   - Введите название (например, "Белая рубашка")
   - Выберите категорию из списка
   - Укажите цвет (например, "белый")
   - Нажмите галочку для сохранения

3. **Добавьте ещё вещей**
   - Повторите процесс для других предметов гардероба
   - Рекомендуется: верх, низ, обувь для полного образа

4. **Создайте первый образ**
   - Перейдите на вкладку "Образы"
   - Нажмите кнопку "+"
   - Выберите 2-4 вещи из гардероба (тапните на фото)
   - Нажмите "Оценить образ"
   - Прочитайте оценку и рекомендации
   - Нажмите галочку для сохранения
   - Введите название образа
   - Нажмите "Создать"

5. **Просмотрите детали**
   - В списке образов тапните на любой образ
   - Увидите все вещи, оценку и рекомендации

### Основные сценарии

#### Сценарий 1: Быстрая оценка лука
```
Гардероб → Образы → (+) → Выбрать вещи → Оценить → Посмотреть результат
```

#### Сценарий 2: Сохранение любимого образа
```
Создать образ → Получить хорошую оценку → Сохранить → Дать название
```

#### Сценарий 3: Очистка гардероба
```
Гардероб → Тап на корзину на вещи → Подтвердить удаление
```

## 🚀 Как запустить проект

### Требования
- **Android Studio**: Hedgehog (2023.1.1+)
- **JDK**: 17
- **Android SDK**: API 26 (минимум), API 34 (целевой)
- **Устройство**: Android 8.0+ или эмулятор

### Шаги

1. **Откройте проект**
   ```bash
   # В Android Studio
   File → Open → Выбрать папку /workspace
   ```

2. **Дождитесь синхронизации Gradle**
   - Автоматически скачает зависимости
   - Может занять 2-5 минут при первом запуске

3. **Создайте эмулятор (если нет физического устройства)**
   ```
   Tools → Device Manager → Create Device
   - Device: Pixel 6
   - System Image: API 34 (Android 14)
   - Finish
   ```

4. **Запустите приложение**
   ```
   Run → Run 'app' (или Shift+F10)
   Выберите устройство/эмулятор
   ```

5. **Первый запуск**
   - Приложение установится и запустится
   - Разрешите доступ к камере/галерее при необходимости

### Сборка APK

```bash
# Debug версия (для тестирования)
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk

# Release версия (для публикации)
./gradlew assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk
```

## 🧪 Тестирование

### Запуск тестов
```bash
# Все тесты
./gradlew test

# Unit тесты
./gradlew testDebugUnitTest

# UI тесты (нужен эмулятор)
./gradlew connectedAndroidTest
```

### Тестовые данные

Для демонстрации рекомендуется добавить:
- 2-3 топа (разных цветов)
- 2-3 низа (брюки, юбки)
- 2-3 пары обуви
- 1-2 платья
- Несколько аксессуаров

Это позволит создать разнообразные образы и протестировать систему оценки.

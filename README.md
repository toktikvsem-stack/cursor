# Fashion Assistant - MVP Android приложение

Мобильный ИИ-модный ассистент для Android, вдохновленный Acloset. Позволяет управлять виртуальным гардеробом, создавать образы и получать оценку луков с помощью встроенного AI-движка.

## 🎯 Основные возможности

### Реализованные функции
- ✅ **Виртуальный гардероб**: Добавление, просмотр и удаление фотографий одежды
- ✅ **Каталогизация**: Сортировка вещей по категориям (верх, низ, платья, обувь, аксессуары)
- ✅ **Конструктор образов**: Создание луков из загруженных вещей
- ✅ **AI-оценка**: Автоматическая оценка образа по 100-балльной шкале
- ✅ **Умные рекомендации**: Советы по улучшению образа
- ✅ **Работа с камерой**: Фото одежды через камеру или загрузка из галереи
- ✅ **Современный UI**: Material Design 3 с поддержкой темной темы

### Убранные сложные функции (для снижения стоимости MVP)
- ❌ AR-примерка
- ❌ Социальная сеть / лента
- ❌ Интеграции с магазинами
- ❌ Погодные рекомендации
- ❌ Календарь образов
- ❌ Облачная синхронизация

## 🤖 AI-движок оценки

Система оценки образов (`OutfitEvaluator`) работает на основе правил и включает:

### Критерии оценки:
1. **Полнота образа** (до 30 баллов)
   - Наличие верха + низа + обуви
   - Или платье + обувь

2. **Гармония цветов** (до 20 баллов)
   - Комбинации нейтральных цветов
   - Теплые/холодные оттенки
   - Акцентные цвета

3. **Сочетаемость категорий** (штрафы за дубликаты)
4. **Бонусы за аксессуары** (+5 баллов)

### Система обратной связи:
- Позитивные отзывы о хорошо подобранных элементах
- Конструктивные рекомендации по улучшению
- Общая оценка от 0 до 100 баллов

**Возможности расширения**: 
- Интеграция с ML-моделями (TensorFlow Lite)
- Анализ стиля через компьютерное зрение
- Персонализированные рекомендации

## 📱 Экраны приложения

1. **Гардероб** - Просмотр всех вещей в виде сетки
2. **Образы** - Список созданных луков с оценками
3. **Добавление вещи** - Фото + информация (название, категория, цвет)
4. **Создание образа** - Выбор вещей из гардероба + AI-оценка
5. **Детали образа** - Подробная информация и рекомендации

## 🚀 Установка и запуск

### Требования
- Android Studio Hedgehog (2023.1.1) или новее
- JDK 17
- Android SDK 26+ (минимальная версия)
- Android SDK 34 (целевая версия)

### Шаги установки

1. **Клонирование репозитория**
```bash
git clone <repository-url>
cd FashionAssistant
```

2. **Открытие в Android Studio**
   - File → Open → Выберите папку проекта
   - Дождитесь синхронизации Gradle

3. **Настройка эмулятора или устройства**
   - Создайте эмулятор через AVD Manager (рекомендуется Pixel 6 с Android 13+)
   - Или подключите физическое устройство с включенной отладкой по USB

4. **Запуск приложения**
   - Нажмите Run (▶️) или Shift+F10
   - Выберите устройство
   - Приложение установится и запустится автоматически

### Сборка APK

```bash
# Debug-версия
./gradlew assembleDebug

# Release-версия
./gradlew assembleRelease
```

APK файлы будут в `app/build/outputs/apk/`

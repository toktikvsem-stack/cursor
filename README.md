# Hello World Application

A simple greeting application that demonstrates a basic user interaction feature.

## Description

This application greets users with "Привет" (Russian for "Hello") and can personalize the greeting with the user's name.

## Usage

Run the application using Python 3:

```bash
python3 hello.py
```

The application will:
1. Display a default greeting: "Привет, World!"
2. Prompt you to enter your name
3. Display a personalized greeting with your name

## Requirements

- Python 3.6 or higher

## Features

- Default greeting functionality
- Personalized greeting based on user input
- Simple and minimal implementation

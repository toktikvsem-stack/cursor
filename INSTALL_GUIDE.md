## 🚀 Как создать APK (3 простых способа)

### Способ 1: Android Studio (рекомендуется) ⭐

**Самый простой и надёжный способ!**

#### Шаг 1: Откройте проект
```
1. Запустите Android Studio
2. File → Open
3. Выберите папку проекта
4. Wait for Gradle sync (2-3 минуты)
```

#### Шаг 2: Создайте APK
```
Build → Build Bundle(s) / APK(s) → Build APK(s)
```

Или нажмите: **Ctrl+Shift+A** → введите "Build APK"

#### Шаг 3: Найдите файл
Android Studio покажет уведомление:
```
┌──────────────────────────────────┐
│ APK(s) generated successfully    │
│ locate                           │ ← Нажмите
└──────────────────────────────────┘
```

Или найдите вручную:
```
проект/app/build/outputs/apk/debug/app-debug.apk
```

**Время**: 5-10 минут при первой сборке, 30 секунд при повторной

## 📱 Как установить APK на телефон

### Вариант A: Через USB + ADB (самый быстрый)

#### Шаг 1: Подготовка телефона
```
1. Настройки → О телефоне
2. Тапните "Номер сборки" 7 раз
3. Появится "Вы стали разработчиком!"
4. Настройки → Для разработчиков
5. Включите "Отладка по USB"
```

#### Шаг 2: Подключение
```
1. Подключите телефон к компьютеру USB кабелем
2. На телефоне появится запрос "Разрешить отладку?"
3. Нажмите "Разрешить"
```

#### Шаг 3: Установка
```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```

Или используйте автоматический скрипт - он сам предложит установить!

**Время**: 10 секунд

---

### Вариант B: Прямая установка (самый простой)

#### Шаг 1: Скопируйте APK на телефон

**Способы передачи**:
- 📧 Email: отправьте себе APK файл
- ☁️ Облако: загрузите в Google Drive / Dropbox
- 💬 Мессенджер: отправьте в Telegram "Избранное"
- 🔌 USB: скопируйте напрямую в папку Downloads

#### Шаг 2: Откройте APK
```
1. На телефоне найдите APK файл
   (Мои файлы → Downloads → app-debug.apk)
2. Тапните на файл
```

#### Шаг 3: Разрешите установку
```
Android спросит: "Разрешить установку из этого источника?"

1. Нажмите "Настройки"
2. Включите переключатель
3. Вернитесь назад
4. Нажмите "Установить"
```

#### Шаг 4: Готово!
```
Приложение "Fashion Assistant" появится 
в списке приложений с фиолетовой иконкой
```

**Время**: 1-2 минуты

---

### Минимальные требования:

✅ **Android Studio**: Hedgehog (2023.1.1) или новее

✅ **JDK**: версия 17

✅ **ОС**: Windows 10+, macOS 10.14+, или Linux

## 🔧 Если возникли проблемы

### Проблема 1: "SDK not found"

**Решение**: Создайте файл `local.properties` в корне проекта:

```properties
sdk.dir=/path/to/Android/Sdk
```

**Где найти путь к SDK**:
```
Android Studio → Settings → 
Appearance & Behavior → System Settings → 
Android SDK → Android SDK Location
```

Примеры:
- Windows: `C:\\Users\\YourName\\AppData\\Local\\Android\\Sdk`
- macOS: `/Users/YourName/Library/Android/sdk`
- Linux: `/home/YourName/Android/Sdk`

---

### Проблема 2: "Java version mismatch"

**Решение**: Установите JDK 17

1. Скачайте: https://adoptium.net/temurin/releases/?version=17
2. Установите
3. Перезапустите Android Studio

Проверка:
```bash
java -version
# Должно быть: openjdk version "17.x.x"
```

---

### Проблема 3: Gradle sync failed

**Решение**:
```bash
# Очистите кэш
./gradlew clean
./gradlew --stop

# В Android Studio:
File → Invalidate Caches / Restart
```

---

### Проблема 4: Out of memory

**Решение**: Откройте `gradle.properties` и увеличьте память:
```properties
org.gradle.jvmargs=-Xmx4096m -Dfile.encoding=UTF-8
```
